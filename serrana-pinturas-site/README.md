# Serrana Pinturas & Reformas em Geral

Site institucional estático, pronto para GitHub e hospedagem na Hostinger.

## Recursos
- Design responsivo preto e dourado
- Página inicial institucional
- Serviços e apresentação de Luciano Pinto
- Página de galeria com filtros e lightbox
- Formulário que abre diretamente o WhatsApp (sem banco de dados)
- Links para Facebook, Instagram e WhatsApp

## Publicação no GitHub
```bash
git init
git add .
git commit -m "Site Serrana Pinturas e Reformas"
git branch -M main
git remote add origin SEU_REPOSITORIO_GITHUB
git push -u origin main
```

## Publicação na Hostinger
Como este projeto é estático, não precisa de Node.js nem banco de dados. Envie o conteúdo desta pasta para `public_html` pelo Gerenciador de Arquivos ou configure uma implantação pelo GitHub, se disponível no seu plano.

## Importante
As imagens da galeria são a base visual do projeto atual. Recomenda-se substituir progressivamente pelas fotos reais das obras da Serrana para que o portfólio represente exclusivamente os trabalhos da empresa.
